This theorem is a relay. It proves `ModelPlaceBuilt2` from `JfSmoothDS`, `GenTransfer` and `JABddOpQQ`, and it supplies one more input to the theorem below it: the realization `JDHatOpQQ` of the hat operators. Its only user is [model places from the gauge transfer and the fibre maps](/entry/formalism-fourier-decay-alt-p-cut-mp-model-place-built2-of-ssn-rep-2/), which proves `JABddOpQQ`.

## Statement

**Theorem.** If `JfSmoothDS`, `GenTransfer` and `JABddOpQQ` hold, then `ModelPlaceBuilt2` holds.

`JABddOpQQ` is stated in [the bounded operators from the fibre maps](/entry/j-abdd-op-qq-of-ssn-rep/).

## Proof

The proof is one line:

```
modelPlaceBuilt2_of_hat hJ hG hat_quadratic_operator_holds hBdd
```

[`modelPlaceBuilt2_of_hat`](/entry/model-place-built2-of-hat/) needs `JDHatOpQQ` in addition. `hat_quadratic_operator_holds` proves it with no hypothesis.

`JDHatOpQQ` says the following. Fix the transfer `trJ`: for a frame $e$ and a function $J$ on the group with values in $\operatorname{Hom}(W_q, W_p)$, $\mathrm{trJ}(J)_\rho(q) = \sqrt{w(q)}\, \langle e_\rho(\zeta), J(g_q) \rangle$, with the Hilbert-Schmidt inner product and $g_q$ the group point of $q$. There is $C_c \ge 0$ such that, at each place $v$ of a setting that is built with $C_c$, for each frame $e$ with `IsFrame`, `IsGauge` and `IsGaugeQQ`, for model level data $L$, and for each $X$ in the hat set of $L$ (the elements $\hat A(Y)$, $R_0(Y)$, $\hat A^\vee(Y)$, $R_0^\vee(Y)$ for $Y \in \mathbb{C}$), there are finitely many pairs $(t_i, \Theta_i)$ with

$$X \cdot \mathrm{trJ}(J) = \sum_i t_i \cdot \mathrm{trJ}(\Theta_i J)$$

for each $J$ in the function space `Q.FFl` on `OmP`. Here $t_i$ lies in the monoid generated by the bounded set of $L$. $\Theta_i$ is a differential operator on the group with smooth coefficients on the region $G_f > 0$; it commutes there with the action $\rho_D(p)$ of each $p$ with `inSS` (`B.Commutes`); the derivatives of its coefficients grow at most like a power of the size function `gN`, with exponent fixed by $C_c (r+1) n$ (`GlobCoef`); and its order is at most $C_c n$, where $n = 2r + k + 1$.

The proof of `hat_quadratic_operator_holds` calls `jDHatOpQQ_of_opA_opR_residue_splitting` with `polynomial_decay_admissible`, `capelli_minors_holds`, `residue_operator_holds`, `residue_splitting_holds`, `mirror_residue_splitting_holds`, `hat_lagrange_decay_holds` and `hat_nodes_decay_holds`. We have not unfolded these.
