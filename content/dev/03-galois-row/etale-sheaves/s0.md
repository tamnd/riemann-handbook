## Statement

The spaces $E$, the groups $H^n(E, \mathbb{Z}/q(i))$ and the condition "$q$ is invertible on $E$" are as in [the power-sum entry](/entry/s57/). For each $q \geq 1$:

1. $f^*(a \cup b) = f^* a \cup f^* b$ for each map $f \colon E \to E'$;
2. $f^* 1 = 1$ if $q$ is invertible on $E'$;
3. $f^* c_1(L) = c_1(f^* L)$ if $q$ is invertible on $E'$;
4. $f^* \kappa(u) = \kappa(f^* u)$ for a map of schemes $f \colon Y \to X$ and a unit $u$ on $X$, if $q$ is a unit on $X$, where $\kappa(u) \in H^1(X, \mathbb{Z}/q(1))$ is the Kummer class.
